## Installation

### Prerequisites
- Install Maven. Download Maven at https://maven.apache.org/index.html.
- Install Java. Download Java at https://www.java.com/en/.
- Install PostgreSQL. Download PostgreSQL at https://www.postgresql.org/. Create a PostgreSQL database for Magician's Hat. The default database name is `magicians_hat`.

### Setup
1. Download the [ZIP file](https://github.com/RWN403/magicians-hat/archive/refs/heads/main.zip) of Magician's Hat.
2. Extract the ZIP file's contents.
3. Open the extracted ZIP folder in a terminal and run `mvn clean install`.

### Run
In the extracted ZIP folder in a terminal, run `mvn exec:java`.
